## Features

1. Register a member, with a name and a unique identifier. (José Adrián)
2. Loan a book to a member. A book that is already on loan cannot be loaned again. (Alex Otero)
3. Return a book, marking it available again. (Steve Robinson)
4. List the books a member currently has on loan. (Bruno Romero)
5. Report the loans that are overdue, given a due date for each loan. (Jaren Pazmiño)
